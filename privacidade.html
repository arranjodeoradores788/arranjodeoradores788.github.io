Política de Privacidade — Arranjo de Oradores

Última atualização: 17 de novembro de 2026.

O Arranjo de Oradores é um programa gratuito para Windows que ajuda congregações a organizar o arranjo de oradores visitantes. Esta política explica quais dados o programa usa, onde eles ficam e como funciona a integração opcional com o Google.

1. Dados que o programa guarda

A pessoa que usa o programa pode cadastrar: nomes de congregações, de responsáveis e de oradores, telefones e e-mails de contato, os temas de discurso que cada orador profere e a programação dos discursos (datas, temas e congregações).

Esses dados ficam no computador de quem usa o programa (na pasta Documentos) e, somente se a pessoa escolher conectar o Google Drive, também num arquivo na conta Google que ela escolher. Nós, que desenvolvemos o programa, não recebemos, não armazenamos e não temos acesso a nenhum desses dados. O programa não tem servidor próprio e não envia dados para terceiros.

2. Integração opcional com o Google

A conexão com o Google é opcional e pode ser desfeita a qualquer momento. Quando a pessoa conecta, o programa solicita somente as permissões abaixo:

  • Identificação básica (openid, email): usada apenas para mostrar, dentro do programa, qual conta está conectada.
  • Google Drive — somente arquivos criados pelo programa (https://www.googleapis.com/auth/drive.file): usada para criar a pasta “Arranjo de Oradores” e o arquivo arranjo-dados.json, e para ler e atualizar esse arquivo, mantendo os dados sincronizados entre os computadores conectados à mesma conta. O programa não vê nem altera nenhum outro arquivo do Drive.
  • Google Agenda — somente o calendário criado pelo programa (https://www.googleapis.com/auth/calendar.app.created): usada para criar o calendário “Arranjo de Oradores” e nele criar, atualizar e remover os eventos dos discursos agendados, com lembretes. Quando o orador tem e-mail cadastrado, ele é incluído como convidado do evento e recebe o convite do Google Agenda. O programa não lê nem altera nenhum outro calendário ou compromisso.

A autorização do Google fica guardada somente no computador da pessoa, criptografada pelo próprio Windows. A comunicação acontece diretamente entre o computador e os servidores do Google.

3. Uso limitado dos dados do Google

O uso e a transferência, para qualquer outro aplicativo, de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. Em especial:

  • os dados do Google são usados somente para oferecer as funções descritas acima, visíveis na tela do programa;
  • os dados não são transferidos para ninguém, nem para nós;
  • os dados não são usados para publicidade, nem vendidos, nem usados para traçar perfis;
  • nenhuma pessoa lê esses dados, a não ser a própria pessoa que usa o programa.

4. Como remover os dados e desconectar

  • No programa, em Backup e ajustes, use “Desconectar” no Google Drive ou no Google Agenda. Isso revoga a autorização.
  • A autorização também pode ser removida a qualquer momento em myaccount.google.com/permissions.
  • A pasta “Arranjo de Oradores” no Drive e o calendário “Arranjo de Oradores” podem ser apagados pela própria pessoa, pelo Google Drive e pelo Google Agenda.
  • Os dados locais ficam em Documentos\Arranjo de Oradores e podem ser apagados pelo programa (“Apagar tudo”) ou pelo Windows. Desinstalar o programa remove a autorização guardada no computador.

5. Dados de terceiros

Quem usa o programa é responsável pelos dados de contato de oradores e responsáveis que cadastrar, e deve usá-los somente para a organização do arranjo de oradores, com o conhecimento das pessoas envolvidas.
